# Futebol 26

Jogo de futebol 2D para 1 ou 2 jogadores, inspirado no FC 26.

## Como jogar

1. Descarrega o repositório (botão verde **Code → Download ZIP** no GitHub) e descompacta.
2. Abre o ficheiro `index.html` no Chrome ou Edge (duplo clique).
3. Carrega **ESPAÇO** para começar.

| Ação                          | J1 (Vermelhos) | J2 (Azuis)     |
|-------------------------------|----------------|----------------|
| Andar                         | W A S D        | Setas          |
| Rematar (segurar = mais força)| F              | Enter          |
| Passar                        | G              | Shift direito  |
| Carrinho                      | Q              | . (ponto)      |
| Mudar de jogador              | R              | / (barra)      |

Nas bolas paradas (livres, cantos, penáltis, laterais) quem marca não anda:
usa as teclas de andar para apontar (aparece uma seta) e depois passa ou remata.

Ver [ESPECIFICACAO.md](ESPECIFICACAO.md) para tudo o que o jogo vai ter.
